# Frontend - Transaction Anomaly Detection

This is the React application for the project.

## Prerequisites
- Node.js installed.

## 1. Installation

Open your terminal and navigate to the `frontend/web/` directory. Install the necessary dependencies:

```bash
cd web
npm install
```

## 2. Running for Development

To start the local development server:

```bash
npm run dev
```

The application will typically be accessible at `http://localhost:5173`.

## 3. Building for Production

To create a production-ready build:

```bash
npm run build
```
